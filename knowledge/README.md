# Chatbot knowledge

The FC Capital chat assistant answers from the Markdown files in this folder.

- One topic per file. Start the file with a `# Title`.
- Split it into `## Sections`. Each section is searched on its own, so keep a section about one thing and write the full question in the heading if you can.
- Only write facts you are sure of. Anything marked "to be confirmed" is treated as not known yet.
- Save, commit and deploy. The bot picks up changes automatically.

This README is not used by the bot.
